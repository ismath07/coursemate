# 📚 CourseMate – Smart Syllabus Access and Examination Scheduling Application

## 📖 About the Project

CourseMate is a smart, role-based mobile application developed using Flutter and Firebase to simplify academic syllabus access and examination management in educational institutions.

The application provides a centralized platform for students and staff to access academic information, view subject-wise syllabi, check examination timetables, and view examination hall allotments.

CourseMate aims to reduce the difficulties of manually searching for academic information by providing an organized, user-friendly, and easily accessible mobile application.

### 🎯 How CourseMate Works

CourseMate provides separate access for Students and Staff, with features based on their respective roles.

### ⚙️ How CourseMate Works

   **User Login:** Students and staff log in through their respective accounts.
   **Role-Based Dashboard:** Users access their role-specific home screens.
   **Syllabus Access:** Browse UG, PG, and Diploma courses, semesters, subjects, and syllabus.
   **Examination Timetable:** Select UG or PG courses to view exam schedules.
   **Hall Allotment:** Students view hall details, while authorized staff manage allotments.
   **Profile Management:** View and manage personal profile details.
